# Contributing to Project-Explainer

Thank you for your interest in contributing! 
This guide will help you get started.

## How to Contribute

1. Fork the repository
2. Create a new branch: `git checkout -b fix/your-feature-name`
3. Make your changes
4. Run tests to make sure nothing is broken
5. Commit: `git commit -m "Fix: describe your change"`
6. Push: `git push origin fix/your-feature-name`
7. Open a Pull Request to the `main` branch

## Code Style

- Follow PEP8 for Python code
- Run `flake8` before submitting (config is in `.flake8`)
- Add comments for complex logic

## Reporting Issues

- Use GitHub Issues to report bugs
- Include steps to reproduce the issue
- Mention your Python version and OS

## Questions?

Open a GitHub Discussion or reach out via the 
C2SI Slack workspace.
